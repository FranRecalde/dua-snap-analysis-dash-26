ℹ️ What a QLA file needs
  • One sheet per paper. Add F or H at the end of the sheet name for tiered papers.
  • A Student Name column in the form Surname, First Name.
  • A Class column.
  • Question labels starting with Q (for example "Q5 School life"). Optional: "Section A" labels above them, and AO1, AO2 or AO3 in the label.
  • A Marks per Q row with the maximum mark for each question.
  • TOTAL MARKS and PERCENTAGE columns at the end. The app recalculates them.
  • A for absent. Leave no other blanks.
  • Works for any subject: sheet names and question labels can be anything.
